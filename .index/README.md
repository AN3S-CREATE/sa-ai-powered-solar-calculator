# Project Context Index

This folder is the living context index for the `sa-ai-powered-solar-calculator-main` repository. It is committed with the project so humans and coding agents can quickly recover an evidence-based understanding of the codebase.

## Usage

1. Read `file-inventory.md` and `architecture.md` before changing the project.
2. Read `key-decisions.md` for work that may affect established technical choices.
3. Read `dead-code.md` before cleanup or refactoring.
4. Update the inventory after every file create, edit, move, or deletion.
5. Record meaningful refreshes in `context-refresh-log.md`.

All entries must come from the current files, use repository-relative paths, and avoid secrets or large copied code blocks.
